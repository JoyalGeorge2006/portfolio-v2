Don't build more. Learn faster.

Every experiment should answer one question.

  • One user.
  • One problem.
  • One change.
  • One metric.
  • One timebox.
  • One decision.

What I track

Activation

Did they do the core action?

Example: Student completed their first coding visualization.

Retention

Did they return without a nudge?

Example: Student returned within 7 days.

Qualitative

What almost stopped them?

Example: Students couldn't understand where to start.

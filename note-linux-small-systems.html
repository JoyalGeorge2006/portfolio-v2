Building small systems on Linux

I like tiny systems that do one thing well — a forwarder, a focus signal, a watcher. Linux + Python is enough to start.

LinuxPythonAutomation

My default stack

  • Python + venv, git for everything.
  • systemd --user or cron to keep it running.
  • Logs to a file first, dashboard later.
  • OpenCV / Telethon only when needed.

Pattern I reuse

# watcher.py — small, readable, restartable
import time
from pathlib import Path

def check():
    # read sensors / api / files
    return True

while True:
    try:
        if check():
            Path("status.txt").write_text("ok")
    except Exception as e:
        print("error:", e)
    time.sleep(60)
Lesson: make it work for one day by hand, then automate day two. Most ideas die from over-building, not under-building.
